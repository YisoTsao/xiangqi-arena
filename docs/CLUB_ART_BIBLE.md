# 暮光遊樂館美術規範（Club Art Bible）

> 版本 0.1 · 最後更新 2026-10-27
>
> 本文件管 3D 遊戲大廳（街口、俱樂部建築、各樓層、角色、NPC）。
> 棋盤、棋子、牌桌上的遊戲畫面仍依 [ART_BIBLE.md](ART_BIBLE.md)。
> 設計稿：世界觀、樓層配置與首批切片見專案的「暮光遊樂館設計稿」。

---

## 1. 美術方向

**「藏在懷舊街區裡、24 小時都亮著燈的遊戲俱樂部」**：台灣老街 × 日式昭和商店街，
Stylized Low-poly，圓潤、可愛、精緻。

三個關鍵字：**圓潤**、**溫暖**、**熟悉**。

### 1.1 一致性是第一優先

整棟樓、整條街、所有角色看起來必須是**同一款遊戲**：

- 麻將館不能像寫實遊戲，網咖不能像賽博龐克，人物不能像來自不同遊戲。
- 各樓層**只換主色燈光與家具種類**，倒角、比例、筆觸、材質規則全部相同。
- 所有模型從同一張調色貼圖取色（見 §4.2），不各自畫貼圖。
- 新資產進場景前必須通過 §10 的驗收清單。

### 1.2 不做的事

- 超寫實材質、照片貼圖、高頻噪點與刮痕。
- 銳利直角（最小倒角見 §3.2）。
- 大面積純黑或純白；最暗用深藍 `#24344D`，最亮用米白 `#F2DAB6`。
- 過度 Bloom 或彩色光暈蓋過形體。

## 3. 比例與尺寸

**1 Three.js 單位 = 1 公尺**。Blender 場景單位設為 Metric、Unit Scale 1.0。

### 3.1 建築與家具（精確值，程式依賴這些尺寸）

| 項目         | 尺寸                                |
| ------------ | ----------------------------------- |
| 模組格線     | 0.5m；牆、地板、柱以 1m / 2m 為單位 |
| 樓層高       | 3.6m（地板到地板）                  |
| 室內樓板     | 約 18m × 12m                        |
| 門           | 寬 1.2m（雙開 2.0m）、高 2.4m       |
| 樓梯         | 寬 1.4m；每階高 0.18m、深 0.28m     |
| 走道最小寬度 | 1.2m；桌與桌間距 ≥ 2.4m             |
| 麻將桌       | 1.0m × 1.0m，桌面高 0.75m           |
| 撲克圓桌     | 直徑 1.4m，桌面高 0.75m             |
| 椅面高       | 0.45m                               |
| 騎樓深度     | 3.0m                                |

### 3.2 造型

- 倒角：家具 ≥ 2cm、建築邊角 ≥ 5cm，用 Bevel modifier（2 段）。
- 誇張比例：門窗、招牌、燈籠比寫實大 10～20%，桌椅維持實際尺寸以免角色坐不準。
- 輪廓優先：從 3/4 俯視 50° 看，每件家具要一眼認得出來。

### 3.3 角色

- Q 版 **3～4 頭身**，基準 3.2 頭身，身高約 1.5m（含頭）。
- 頭大手短，手掌簡化為連指手套形；眼睛為貼圖，不建模。
- 所有玩家角色、NPC 共用同一副骨架（§7）。

## 4. 材質

### 4.1 手繪風格 PBR

- 使用 glTF 標準 `MeshStandardMaterial`。
- **低噪點**：顏色以大色塊為主，只在木頭、磨石子加一層低對比筆觸紋。
- **柔和粗糙度**：roughness 0.55～0.9；只有玻璃、霓虹壓克力、拋光茶具低於 0.4。
- metalness 只用 0 或 1（招牌框、鐵窗、電車），不用中間值。
- 不使用 normal map 做細節，形體靠建模與倒角；例外是磨石子與磁磚可用一張共用 normal。

### 4.2 共用調色貼圖

- `TEX_palette_atlas.png`，512×512，切成 8×8 色格，每格有輕微漸層。
- 家具與建築的 UV 直接打到色格上，多數物件不需要專屬貼圖。
- 需要圖案的物件（招牌字、海報、麻將牌面、撲克牌）用另一張 `TEX_decal_atlas`，2048×2048。

### 4.3 材質清單

| 材質       | 基礎色        | roughness | 備註                       |
| ---------- | ------------- | --------- | -------------------------- |
| 木頭       | 暖木棕系      | 0.75      | 低對比筆觸紋               |
| 磨石子     | 米白 + 色點   | 0.6       | 共用 normal                |
| 舊磁磚     | 米白 / 淡綠   | 0.55      | 縫線畫在貼圖上             |
| 磨砂玻璃   | 米白 30% 透明 | 0.3       | 夜晚背面加自發光模擬窗光   |
| 烤漆金屬   | 深藍 / 復古綠 | 0.5       | metalness 1                |
| 霓虹壓克力 | 主色          | 0.2       | emissive，強度依時段（§5） |
| 布料       | 主色降飽和    | 0.9       | 麻將桌絨布、沙發           |

## 5. 燈光與日夜

### 5.1 時鐘

現實 2 小時 = 遊戲 1 天（遊戲 1 小時 = 現實 5 分鐘）。
遊戲時間由 UTC 算出：`gameHour = (Date.now() / 300_000) % 24`，所有玩家一致，不需伺服器同步。
設定提供「固定夜晚」。

### 5.2 四個時段

| 時段 | 遊戲時間    | 太陽           | 天空                | 霓虹     | 街上                       |
| ---- | ----------- | -------------- | ------------------- | -------- | -------------------------- |
| 早晨 | 06:00–09:00 | 低角度暖白     | 淡橘 → 淡藍         | 關       | 地面濕、店員拉鐵捲門、掃地 |
| 白天 | 09:00–17:00 | 高角度白光     | 晴藍、少量雲        | 關       | NPC 最多、電車班次密       |
| 傍晚 | 17:00–19:00 | 低角度橘紅逆光 | 橘 → 紫             | 逐盞亮起 | 下班人潮、長影             |
| 夜晚 | 19:00–06:00 | 無（月光弱藍） | 深藍 `#24344D` → 紫 | 全亮     | 路面反光、俱樂部最熱鬧     |

時段之間以關鍵影格內插太陽方向、天空色、半球光、霓虹 emissive 強度；每 5 秒更新一次即可。

### 5.3 室內與室外的分工

- **室外（街口）**：即時方向光（太陽）+ 半球光；陰影只在高畫質開。建築 AO 烘在頂點色或 lightmap。
- **室內**：燈一直開著，不隨時間變暗。燈光在 Blender 用 Cycles 烘成 lightmap（`TEX_<樓層>_lightmap`，1024～2048）。
  只有窗外天色與從窗戶進來的光跟著時鐘變（一盞隨時段調色的面光）。
- **角色**：不吃 lightmap，用半球光 + 圓形假影。
- Bloom 只作用在 emissive，強度上限 0.6；低畫質關閉。

## 6. 鏡頭

- 第三人稱 3/4 俯視，俯角 50°，距離 9m，FOV 35°；水平旋轉限制 ±60°。
- 室內靠鏡頭的牆與天花板自動淡出。
- 首頁鏡頭：遠景緩慢平移；按「進入遊戲」後 2 秒推進到俱樂部門口，與遊戲內街道為**同一個場景**。
- 坐下：0.8 秒推到桌面視角，交給遊戲畫面（依 ART_BIBLE.md）。

## 7. 角色與動畫

- 一副人形骨架 `CHAR_rig_base`（≤ 30 根骨頭），所有玩家角色與 NPC 共用。
- 零件：頭、髮型、上衣、下身、鞋、配件，各自為獨立 mesh，綁同一副骨架，換裝 = 換 mesh。
- 每個完整角色 ≤ 8k 三角面、≤ 2 個材質。
- 首批動畫：`ANIM_idle`、`ANIM_walk`、`ANIM_run`、`ANIM_turn`、`ANIM_sit`、`ANIM_stand`、
  `ANIM_wave`、`ANIM_clap`、`ANIM_cheer`、`ANIM_interact`。以 glTF animation 匯出，30fps。
- 店犬麻糬另有四足骨架，動畫：待機、走、跑、趴睡、搖尾。

## 8. Blender 製作與匯出

### 8.1 製作分工

| 類型                                 | 方式                          |
| ------------------------------------ | ----------------------------- |
| 建築、牆、地板、樓梯、門、桌椅、櫃台 | **Blender 手工精確建模**      |
| 座位錨點、站立點、碰撞盒、互動範圍   | **Blender 空物件與方塊**      |
| 招牌、盆栽、茶具、海報、小擺設       | AI 輔助初稿 → Blender 修正    |
| 角色                                 | Blender 手工；AI 只做概念參考 |

行走、碰撞、座位與樓層切換依賴可靠的尺寸，所以這些一律不用 AI 生成模型。

### 8.2 命名

| 前綴     | 用途                 | 例                            |
| -------- | -------------------- | ----------------------------- |
| `ENV_`   | 建築與場景模組       | `ENV_wall_2m_window`          |
| `PROP_`  | 道具、家具           | `PROP_mahjong_table`          |
| `CHAR_`  | 角色與零件           | `CHAR_hair_twintail`          |
| `ANIM_`  | 動畫                 | `ANIM_sit`                    |
| `TEX_`   | 貼圖                 | `TEX_palette_atlas`           |
| `SFX_`   | 音效                 | `SFX_tile_clack`              |
| `UI_`    | 介面圖               | `UI_sign_board`               |
| `COL_`   | 碰撞方塊（不渲染）   | `COL_counter`                 |
| `SEAT_`  | 座位錨點（空物件）   | `SEAT_t1_s0`（1 號桌 0 號位） |
| `STAND_` | 起身後站立點         | `STAND_t1_s0`                 |
| `TRIG_`  | 互動範圍、換場景觸發 | `TRIG_door_1F`                |

空物件的 +Y 軸 = 角色面向。程式只讀這些名稱，不依賴物件在階層中的位置。

### 8.3 匯出設定

- 格式 GLB；+Y Up；套用所有 modifier；不匯出相機與燈光（燈光由程式建立）。
- 幾何壓縮 Meshopt；貼圖 KTX2（ETC1S 一般、UASTC 給招牌字與牌面）。
- 一個樓層一個 GLB（`ENV_floor_1F.glb`），共用家具另存並以 Instancing 擺放。
- 原始檔 `.blend` 放在 repo 外的美術儲存空間；repo 只收匯出後的 GLB 與貼圖。

## 9. AI 輔助規則

- 可用在：概念圖、配色探索、道具參考、Tripo.ai 小道具初稿。
- AI 產出的模型必須人工完成：重拓樸（三角面符合 §11）、比例對齊格線、改用調色貼圖、檢查授權。
- 每件進場景的 AI 輔助資產都要在 `ASSET_MANIFEST.md` 標明工具、原始提示或來源與授權狀態。
- 未完成上述檢查的資產不得進入正式版本。

## 12. 目前的程式化做法（尚未導入 GLB 前）

場景暫時用程式產生的模型與貼圖，做法如下，日後換成 GLB 時沿用同一套燈光與後處理：

- **貼圖**：`components/club/textures.ts` 以 Canvas 產生木紋、木地板、磨石子、復古磁磚、壁紙、絨布、紙門、外牆磁磚、柏油、地磚、鐵捲門，`tiled()` 依重複次數快取。
- **模型**：倒角方塊（`RoundedBoxGeometry`，依尺寸快取）組成家具與建築細節；角色為 3 頭身 toon 材質 + 外框線。
- **燈光**：暖色主光 + 半球光；室內每桌一盞吊燈點光（低畫質只開前排三盞）、櫃台燈、入口補光；紙窗夜晚透冷光。地面光圈用加法混合貼片假造。
- **後處理**：N8AO（高畫質）、Bloom、色相飽和、亮度對比、ACES 色調映射、暗角、SMAA；低畫質全部關閉。
- **合併**：`Bake` 把材質相同的靜態 mesh 合併成一個 draw call，原 mesh 隱藏但保留點擊。
- **鏡頭**：3/4 斜俯視，室內轉 0.55 rad 並切開前牆與右牆（剖面）；輸入依鏡頭方向換算。
- **截圖**：`/club?hour=20&q=medium&spawn=hall` 直接站在 1F 室內；`?perf=1` 在 `window.__clubPerf` 提供 draw call、三角面與 fps。
- 首頁主視覺 `public/club/keyart-*.jpg` 是這個場景的實際算圖，場景大改後要重新截取。

無頭瀏覽器（SwiftShader）的幀率不能代表實機，§11 的預算仍待實機量測。
