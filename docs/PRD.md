# Xiangqi Arena — 產品需求文件（PRD）

> 版本 0.1 · 最後更新 2026-10-26

## 1. 產品定位

Xiangqi Arena 是一款**免註冊即可遊玩的線上雙人象棋競技場**，提供精緻的 2.5D 立體棋盤，
支援**傳統大盤象棋**與**台灣暗棋**兩種模式，在桌面與手機瀏覽器皆可流暢操作。

一句話：_「傳一個房間代碼給朋友，三秒後就能開始下棋。」_

## 2. 目標使用者

| 類型                   | 需求                 | 本產品的回應                               |
| ---------------------- | -------------------- | ------------------------------------------ |
| 想跟朋友隨手下一盤的人 | 不想註冊、不想裝 App | 建立房間 → 複製連結 → 開下                 |
| 習慣實體棋盤的玩家     | 介面要像真的棋盤     | 2.5D 木質棋盤、立體棋子、中文記譜          |
| 手機玩家               | 單手、小螢幕也要好點 | 棋盤優先版面、可收合面板、觸控放大的點擊區 |
| 規則嚴謹的棋友         | 長將、長捉要判得對   | 明確採用亞洲象棋規則並以測試固定行為       |

## 3. 核心價值主張

1. **零摩擦**：不需帳號、不需安裝，一個連結即可對弈。
2. **視覺質感**：不是 HTML 表格棋盤，而是有厚度、倒角、雕刻文字與接觸陰影的立體棋子。
3. **規則正確**：規則引擎獨立、具完整單元測試，伺服器權威判定，不會因為前端 bug 而算錯勝負。
4. **連線穩定**：斷線自動重連、重新整理頁面能回到原座位與原棋局。

## 5. 使用者流程

```
首頁
 ├─ 開始遊戲 ─────────────┐
 ├─ 建立房間（選模式/計時）┤→ 房間大廳 ─→ 雙方準備 ─→ 對戰頁 ─→ 結束彈窗 ─→ 再來一局
 ├─ 加入房間（輸入代碼）──┘                                              └─→ 離開
 └─ 同裝置對戰 ────────────────────────────→ 對戰頁
```

## 6. 非功能需求

| 項目       | 目標                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 首次可互動 | 桌面 < 2.5s、手機 4G < 4s                                            |
| 操作延遲   | 同區域 < 150ms 收到伺服器確認                                        |
| 畫面更新   | 桌面 60fps、中階手機 ≥ 30fps                                         |
| 相容性     | Chrome / Edge / Safari / Firefox 最新兩版；無 WebGL 時自動降級       |
| 可及性     | 所有操作可鍵盤觸達、按鈕有 aria-label、尊重 `prefers-reduced-motion` |
| 成本       | 以免費方案起步，不使用付費套件                                       |

## 7. 成功指標（上線後觀察）

- 建立房間後成功開始對局的比率 > 70%
- 對局中途因連線問題中斷的比率 < 3%
- 行動裝置誤點（點到非預期棋子）回報 < 1%
