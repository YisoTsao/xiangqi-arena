# 棋規文件

> 版本 0.1 · 最後更新 2026-10-26
>
> 本文件說明本專案**實際實作**的規則，以及在多套規則體系中選定哪一套、為什麼。
> 每條規則都有對應的單元測試；修改規則前請先看測試。

---

## 1. 規則體系的候選與選定

### 1.1 象棋

| 候選                          | 說明         | 長將 | 長捉             | 困斃 |
| ----------------------------- | ------------ | ---- | ---------------- | ---- |
| **亞洲象棋聯合會規則（AXF）** | 亞洲賽事通用 | 判負 | 判負             | 判負 |
| 中國象棋協會規則（CXA 2011）  | 中國國內賽事 | 判負 | 判負（分類細緻） | 判負 |
| 香港 / 民間休閒規則           | 街頭常見     | 判和 | 判和             | 判負 |

**選定：亞洲象棋聯合會規則（AXF）的簡化實作**，理由：

1. 與台灣、香港、東南亞棋友的習慣最接近。
2. 「長將判負」符合多數人的直覺，不會讓劣勢方靠長將逃和。
3. 困斃（無子可動）判負是中式象棋與國際象棋最大的差異，必須正確實作。

休閒規則可透過設定切換：

```ts
createXiangqiGame({ rules: { perpetual: 'draw' } }); // 任何循環一律判和
```

### 1.2 暗棋

暗棋各地規則差異極大（階級、炮吃法、翻棋定色、和棋條件都不同）。
本專案把規則做成 `BanqiRules`，**預設為台灣常見玩法**：

| 選項                       | 預設                           | 其他地方的做法           |
| -------------------------- | ------------------------------ | ------------------------ |
| `kingCanCapturePawn`       | `false`（將帥不能吃兵卒）      | 部分規則允許             |
| `pawnCanCaptureKing`       | `true`（兵卒可吃將帥）         | 部分規則禁止             |
| `equalRankCapture`         | `true`（同階可互吃）           | 部分規則同歸於盡或不可吃 |
| `cannonJumpCapture`        | `true`（隔一子跳吃，不限距離） | 部分規則限相鄰一格       |
| `cannonCapturesAnyRank`    | `true`（炮跳吃不看階級）       | 部分規則炮也要比大小     |
| `cannonCanCaptureAdjacent` | `false`（炮不能吃相鄰）        | 部分規則可以             |
| `noProgressDrawPlies`      | `50`                           | 30～60 不等              |
| `repetitionDrawCount`      | `3`                            | 部分規則不判和           |

## 2. 大盤象棋

### 2.1 棋盤與座標

- 9 條縱線 × 10 條橫線，棋子落在**交點**。
- 程式內部索引：`square = rank * 9 + file`，`file 0..8`（紅方左至右），`rank 0..9`（紅方底線為 0）。
- ICCS 座標：`a0`～`i9`（`a0` = 紅方左下角）。
- FEN：採通用象棋 FEN，初始局面
  `rnbakabnr/9/1c5c1/p1p1p1p1p/9/9/P1P1P1P1P/1C5C1/9/RNBAKABNR w`。

### 2.2 棋子走法

| 棋子   | 走法                                       | 限制                                       |
| ------ | ------------------------------------------ | ------------------------------------------ |
| 帥／將 | 九宮內直行一步                             | 不得與對方帥將同線照面且中間無子           |
| 仕／士 | 九宮內斜行一步                             | —                                          |
| 相／象 | 田字（斜兩格）                             | 不得過河；**象眼**（田字中心）有子則不可走 |
| 俥／車 | 直線任意距離                               | 不可越子                                   |
| 傌／馬 | 日字                                       | **馬腳**（相鄰的直行方向）有子則不可走     |
| 炮／砲 | 移動同車；吃子需隔**恰好一個**棋子（炮架） | 炮架與目標之間不可再有子                   |
| 兵／卒 | 向前一步；過河後可左右各一步               | 不可後退                                   |

### 2.3 將軍與合法性

- 一步棋走完後，若己方帥將被攻擊，該步**不合法**。
- 將帥照面（同縱線、中間無子）視同被將軍，因此任何造成照面的步都不合法。
- 擋在兩個帥將之間的棋子因此被「釘住」，只能沿該縱線移動。

### 2.4 勝負

| 結果 | 條件                          | 內部原因碼        |
| ---- | ----------------------------- | ----------------- |
| 將死 | 被將軍且無合法步              | `checkmate`       |
| 困斃 | 未被將軍但無合法步 → **判負** | `stalemate`       |
| 認輸 | 玩家主動                      | `resign`          |
| 超時 | 時間用盡                      | `timeout`         |
| 斷線 | 斷線超過 90 秒                | `abandon`         |
| 長將 | 見 §2.6                       | `perpetual-check` |
| 長捉 | 見 §2.6                       | `perpetual-chase` |

### 2.5 和棋

| 結果             | 條件                                  | 原因碼                  |
| ---------------- | ------------------------------------- | ----------------------- |
| 協議和棋         | 一方提議、對方接受                    | `agreement`             |
| 重複局面         | 同一局面出現 3 次且雙方皆非長將／長捉 | `repetition`            |
| 雙方皆長將／長捉 | 兩方行為相同                          | `mutual-perpetual`      |
| 自然限著         | 連續 120 個半回合（60 回合）無吃子    | `move-limit`            |
| 子力不足         | 場上無任何車、馬、炮、兵              | `insufficient-material` |

### 2.6 長將與長捉（重點）

判定時機：當某個局面第 3 次出現時，檢視**最近一個循環**內雙方的行為：

- `check`：該方在循環中**每一步都將軍**。
- `chase`：該方每一步都是將軍或「捉」。
- `idle`：其他。

判決：

| 紅          | 黑          | 結果                               |
| ----------- | ----------- | ---------------------------------- |
| idle        | idle        | 和棋（`repetition`）               |
| check/chase | idle        | 紅判負                             |
| idle        | check/chase | 黑判負                             |
| check       | check       | 和棋（`mutual-perpetual`）         |
| chase       | chase       | 和棋（`mutual-perpetual`）         |
| check       | chase       | **長將方判負**（長將責任大於長捉） |

**「捉」的定義（本專案的實作）**：一步棋走完後，走棋方**新產生**一個可合法吃掉對方
非將帥棋子的威脅，且滿足下列任一條件：

1. 被捉子無保護（對方無法合法回吃該點）；或
2. 被捉子價值高於攻擊子（車 9 > 炮 4.5 > 馬 4 > 仕／相 2 > 兵 1）。

例外（不算捉）：

- 將帥與兵卒的攻擊不算捉。
- 捉對方的將帥屬於「將軍」，不是捉。
- 捉**未過河的兵卒**不算捉。

> **⚠️ 已知限制（待確認的規則決策 R-1）**
> 真正的 AXF 規則對「捉」有更細緻的分類（例如「解拆」「兌子」「獻」「有根子被
> 跟捉」等），本實作採用上述簡化判準。在一般對局中結果與正式規則一致，但在複雜的
> 兌子循環中可能有出入。需要賽事級精確度時，應擴充 `packages/game-xiangqi/src/chase.ts`。

### 2.7 記譜

採傳統中文記譜：紅方用「一二三四五六七八九」由右至左，黑方用「１２３…」由左至右。

- 平移：`炮二平五`
- 進退（帥、車、炮、兵以格數計）：`俥一進一`
- 進退（仕、相、馬以目標縱線計）：`馬８進７`
- 同線同名棋子用前／中／後：`前俥進二`、`後俥平八`

另外保留 ICCS 座標記譜（`h2-e2`）供程式使用。

## 3. 暗棋（台灣規則）

### 3.1 棋盤與配子

- 4 列 × 8 行，共 32 格，棋子落在**格子**內。
- 索引：`cell = row * 8 + col`，命名 `a1`～`h4`。
- 每方 16 子：帥／將 ×1、仕／士 ×2、相／象 ×2、俥／車 ×2、傌／馬 ×2、炮／砲 ×2、兵／卒 ×5。
- 開局：32 子洗牌後**全部蓋牌**。洗牌結果只存在伺服器（見 §3.7）。

### 3.2 行動

輪到的一方必須擇一：

1. **翻棋**：翻開任意一顆蓋著的棋子。
2. **移動**：移動己方任一顆已翻開的棋子到**正交相鄰**的空格。
3. **吃子**：移動到相鄰格並吃掉對方已翻開的棋子（需符合 §3.4）。
4. **炮的跳吃**：見 §3.5。

> 蓋著的棋子不能被移動，也不能被（除了炮以外的方式）吃掉。

### 3.3 翻棋定色

**第一位翻棋者，翻出什麼顏色就執什麼顏色。** 另一方自動取得另一色。
在第一顆棋子翻開之前，雙方都沒有陣營，只能翻棋。

### 3.4 階級與吃子

```
帥／將(7) > 仕／士(6) > 相／象(5) > 俥／車(4) > 傌／馬(3) > 炮／砲(2) > 兵／卒(1)
```

- 高階可吃低階，**同階可互吃**。
- **兵／卒可以吃帥／將**（以小博大）。
- **帥／將不可以吃兵／卒**。
- 炮的吃法特殊，見下。

### 3.5 炮／砲

- **移動**：與其他棋子相同，走相鄰一格。
- **吃子**：必須沿直線（上下左右）隔**恰好一顆**棋子（炮架）跳吃，距離不限。
  - 炮架可以是任何棋子，**包括蓋著的棋子**與己方棋子。
  - 目標必須是**已翻開**的對方棋子。
  - 吃子不受階級限制（炮可以跳吃將帥）。
- **不可吃相鄰的棋子**（預設規則；`cannonCanCaptureAdjacent` 可開啟）。

### 3.6 勝負與和棋

| 結果 | 條件                                     | 原因碼                           |
| ---- | ---------------------------------------- | -------------------------------- |
| 勝   | 對方棋子全被吃光                         | `no-pieces`                      |
| 勝   | 對方無任何合法行動（無子可翻、無子可動） | `no-moves`                       |
| 勝   | 認輸／超時／斷線                         | `resign` / `timeout` / `abandon` |
| 和   | 連續 50 個半回合無翻棋、無吃子           | `move-limit`                     |
| 和   | 同一局面出現 3 次                        | `repetition`                     |
| 和   | 雙方同意                                 | `agreement`                      |

### 3.7 隱藏資訊的安全要求

1. 洗牌結果只存在伺服器記憶體中（`BanqiState.cells`）。
2. 送給客戶端的快照中，未翻開的棋子**只有 `id` 與 `faceUp: false`**，沒有 `side` 與 `kind`。
3. 協定層 `CellViewSchema` 以 discriminated union 讓「蓋牌帶身分」在執行時驗證失敗。
4. 測試會把整份快照 JSON 轉成字串，掃描是否含有未翻開棋子的身分欄位。
5. 本機 hot-seat 模式在瀏覽器洗牌（同一台裝置、兩人共用螢幕，無隱藏需求），
   **線上對戰永不使用**此路徑。

## 4. 大老二（台灣規則，四人）

實作在 `games/big-two`（`combos.ts` 牌型、`engine.ts` 流程）。

### 4.1 發牌與先手

- 一副 52 張，四人各 13 張，伺服器洗牌。
- 持有**梅花 3** 的人先出，第一手必須包含梅花 3（可以是單張、對子或五張牌型）。
- 再來一局時仍由梅花 3 持有者先出（不由上一局贏家先出）。

### 4.2 大小

- 點數：3 < 4 < … < K < A < 2。
- 花色：梅花 ♣ < 方塊 ♦ < 紅心 ♥ < 黑桃 ♠。
- 單張先比點數再比花色；對子比較大的那一張（同點數時有黑桃的大）。

### 4.3 牌型

| 牌型   | 張數 | 比較方式                     |
| ------ | ---- | ---------------------------- |
| 單張   | 1    | 點數、花色                   |
| 對子   | 2    | 較大那張                     |
| 順子   | 5    | 順子等級，再比最大那張花色   |
| 葫蘆   | 5    | 三張的點數                   |
| 鐵支   | 5    | 四張的點數（四條必須帶一張） |
| 同花順 | 5    | 同順子                       |

- 五張牌型之間：同花順 > 鐵支 > 葫蘆 > 順子，可以互壓。
- 順子等級：34567 最小 … 10JQKA，再來 A2345，**23456 最大**。JQKA2、QKA23、KA234 不算順子。
- **不採用**三條（單出三張）與同花。

### 4.4 流程

- 跟牌必須出相同張數且更大的牌，或選擇「過」。
- 其他三家都過時，最後出牌的人自由出牌（可換張數）；自由出牌時不能過。
- 過牌之後同一輪仍可以再出（只要輪到你）。

### 4.5 勝負與名次

- 最先出完手牌的人獲勝；其餘依剩餘張數排名，同張數時依勝者之後的出牌順序。
- 認輸、超時或斷線逾時：本局立即結束，該玩家最後一名，其餘三家剩牌最少者獲勝。
- 名次寫入 `game_room.match_players.placement`；勝者記 win，其餘記 loss。
- 結算畫面顯示參考罰分（剩幾張扣幾分，10 張以上加倍，13 張三倍），目前不累計。

### 4.6 隱藏資訊

- 伺服器只把觀看者自己的手牌送給他，其他人只有張數；觀戰者沒有任何手牌。
- 對局結束後才公開四家剩下的牌。
- 前端的出牌預覽與「提示」只用自己看得到的資料計算，最終合法性由伺服器判定。

## 5. 麻將（台灣 16 張，四人）

實作在 `games/mahjong`（`hand.ts` 拆牌與聽牌、`scoring.ts` 台數、`engine.ts` 流程）。
規則逐條確認紀錄見專案檔案「台灣16張規則確認」（2026-10-27，全部採用建議，編號 M-1～M-33）。

### 5.1 牌與發牌

- 144 張：萬、筒、條各 36，字牌 28（東南西北中發白），花牌 8（春夏秋冬、梅蘭竹菊）。
- 伺服器洗牌；擲骰開門只是畫面動畫。每一把的洗牌由對局開始時的種子推出，種子只存在伺服器。
- 首局莊家由伺服器亂數決定。莊家 17 張、閒家 16 張。
- 從莊家起依序補花：花牌亮出，從牌尾補一張，補到沒有花為止。對局中摸到花也一樣。
- 牌牆剩 16 張時流局（不再摸牌，也不再補牌）。

### 5.2 一手的流程

1. 輪到的人摸一張（第一手的莊家不摸），可以**自摸**、**暗槓**、**加槓**或**打一張**。
2. 打出後，其他三家都要回應：胡、碰、槓、吃（只有下家可吃）或過。
3. 三家都回應後依 **胡 > 碰／槓 > 吃** 處理：
   - 多家同時胡：**截胡**，由放槍者下家起最近的一家胡。
   - 碰或吃之後直接打牌（不摸牌、不能自摸）；明槓後從牌尾補牌。
   - 都過：下家摸牌。
4. **加槓**時先開放其他三家**搶槓**；沒人搶才完成槓並補牌。
5. **過水**：能胡卻不胡（包括改喊碰），到自己下次摸牌之前都不能胡同一種牌。

隱藏資訊：每次打牌後三家**都**列為「待回應」，不論能不能吃碰胡，避免從「在等誰」推出手牌。
別人的回應在結算前不公開。前端應對「沒得吃碰」的情況用固定的短暫延遲自動送出「過」。

### 5.3 胡牌

- 一般牌型：5 組面子（順子、刻子、槓）+ 1 對眼。
- 不採用嚦咕嚦咕等特殊牌型。
- 八仙過海：集滿 8 張花立刻胡（自摸）。七搶一：手上 7 張花時，別人補出第 8 張花即胡（補花者付）。
- 伺服器判定胡牌，不會發生詐胡、相公。

### 5.4 台數

同一手牌有多種拆法時取台數最高者。台數無上限。

| 牌型                   | 台         | 說明                                                                       |
| ---------------------- | ---------- | -------------------------------------------------------------------------- |
| 莊家                   | 1          | 莊家參與的那一筆（莊家胡、莊家放槍、莊家被自摸）                           |
| 連莊、拉莊             | 2N         | 連 N 拉 N，和莊家同樣只算莊家參與的那一筆                                  |
| 門清                   | 1          | 沒有吃碰明槓（暗槓不影響）                                                 |
| 自摸                   | 1          |                                                                            |
| 門清自摸               | 3          | 取代門清與自摸                                                             |
| 門風、圈風             | 各 1       | 刻子；有大小四喜時改算四喜                                                 |
| 三元牌                 | 各 1       | 中發白刻子；有大小三元時改算三元                                           |
| 花牌                   | 各 1       | 自己座位的花（東：春梅、南：夏蘭、西：秋竹、北：冬菊）                     |
| 花槓                   | 2          | 春夏秋冬或梅蘭竹菊四張到齊，取代該組的座位花                               |

| 搶槓                   | 1          |                                                                            |

| 平胡                   | 2          | 全順子、無字無花、兩面聽、非自摸                                           |
| 獨聽                   | 1          | 胡牌前只聽一種牌（邊張、中洞、單吊）；全求人、平胡不另計                   |
| 三暗刻／四暗刻／五暗刻 | 2／5／8    | 胡別人打出的牌湊成的刻子不算暗刻                                           |
| 碰碰胡                 | 4          |                                                                            |
| 混一色／清一色         | 4／8       |                                                                            |

### 5.5 結算

- 每一筆 = 底 3 分 + 台數 × 1 分（莊家參與的那一筆再加莊家台）。只是點數，不對應金錢。

### 5.6 莊家與一將

- 莊家胡或流局：連莊。閒家胡：下莊，由下家做莊。

- 整將結束依點數排名次；同分時從第一把的莊家起依座位順序。點數最高者為勝者。
