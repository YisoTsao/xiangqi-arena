## 1. 方向：Stylized Premium 3D

**1980–1990 年代台灣老街 × 日本昭和商店街的架空懷舊城市**。不是寫實，也不是塑膠玩具：

- 形體圓潤、比例略誇張（門窗、招牌大 10～20%），但**表面有真實材質的層次**：磁磚有縫和釉光、柏油有骨材和積水、木頭有紋理和磨損、金屬有環境反光。
- 暖色店面與霓虹 × 冷色暮光。暗部保留細節，不死黑；亮部只有自發光物件會暈開。
- 生活感來自「被使用過的痕跡」：雨痕、招牌支架、電線、冷氣滴水、盆栽、機車，而不是堆滿道具。

### 1.1 品質底線（不接受的東西）

| 不接受                                           | 改成                                            |
| ------------------------------------------------ | ----------------------------------------------- |
| Box/Cylinder/Sphere 拼裝的建築、家具、角色當成品 | Blender 製作的 GLB（暫代模型必須在清單標 TODO） |
| 單色 `color` 材質、只有 albedo 的貼圖            | albedo + normal + ORM 的 PBR 組                 |
| 發光方塊當窗戶                                   | 室內映射窗或真的看得到室內的玻璃                |
| 所有亮面都 Bloom                                 | Bloom 門檻 0.95，只有 emissive 超過 1 的會暈    |
| 每盞裝飾燈都開動態陰影                           | 只有太陽投影；其餘用不投影的局部光 + 烘焙 AO    |

## 3. 比例

- 1 單位 = 1 公尺；樓層高 3.6m；騎樓深 3m；門 2.4m 高。
- 角色 3～3.5 頭身、身高約 1.5m；桌椅維持實際尺寸（角色要坐得準）。
- 招牌字的最小可讀高度：開場鏡頭下 ≥ 畫面高 3%，跟隨鏡頭下 ≥ 2.5%。

## 4. 材質

### 4.1 PBR 貼圖組

每組三張 WebP，放在 `apps/web/public/club/textures/<name>/`：

| 檔名          | 內容                                                | 色彩空間 |
| ------------- | --------------------------------------------------- | -------- |
| `albedo.webp` | 底色（不含光影）                                    | sRGB     |
| `normal.webp` | 切線空間法線，OpenGL 慣例（+Y 向上，three.js 預設） | 線性     |
| `orm.webp`    | R = AO、G = roughness、B = metalness（glTF 慣例）   | 線性     |

- 貼圖以「一張代表幾公尺」設計，程式用 `usePbr(set, [寬, 高], 每張公尺數)` 算重複次數，不要用拉伸對齊。
- 需要依建築變色的（外牆磁磚、水泥）把 albedo 做成接近白色，由材質 `color` 乘上各棟的牆色，一組貼圖全街共用。
- 高頻細節放 normal，不放 albedo；albedo 只有低對比的色差。

### 4.2 目前的貼圖組

| 名稱             | 一張代表 | 用途                     | roughness 範圍   |
| ---------------- | -------- | ------------------------ | ---------------- |
| `asphalt`        | 4m       | 馬路，低窪處有積水       | 0.2（積水）～0.9 |
| `arcade_tile`    | 1.2m     | 騎樓與人行道的陶磚格紋   | 0.3～0.9         |
| `facade_tile`    | 1m       | 二丁掛外牆磁磚（釉面）   | 0.2～0.9         |
| `concrete`       | 1～3m    | 緣石、排水溝、遠處地面   | 0.6～1           |
| `wood_floor`     | 1.2m     | 1F 柚木長條地板（清漆）  | 0.38～0.95       |
| `terrazzo_floor` | 1.5m     | 玄關磨石子（拋光）＋銅條 | 0.2～0.6         |
| `wall_tile`      | 0.6m     | 綠色馬賽克腰牆           | 0.3～0.9         |
| `wallpaper`      | 0.8m     | 腰牆以上壁紙             | 0.8～0.95        |

### 4.3 材質類型的參數

| 類型         | roughness  | metalness | envMapIntensity | 備註                         |
| ------------ | ---------- | --------- | --------------- | ---------------------------- |
| 木頭         | 0.65～0.8  | 0         | 1               | 紋理方向跟木料走             |
| 漆面金屬     | 0.35～0.5  | 1         | 1               | 鐵窗、招牌框、路燈           |
| 釉面磁磚     | 0.3～0.5   | 0         | 1               | 縫粗糙                       |
| 玻璃（櫥窗） | 0.05       | 0         | 1.1             | 透明 0.12，看得到室內        |
| 布料         | 0.85～0.95 | 0         | 0.5             | 暖簾、雨棚、窗簾             |
| 霓虹壓克力   | 0.2～0.45  | 0         | 1               | emissive，`toneMapped=false` |

### 4.4 窗戶

- **看得到真室內的窗**（1F 麻將館櫥窗）：透明玻璃 + 環境反射。
- **看不到真室內的窗**（樓上、鄰居）：`InteriorWindow` 室內映射 shader（後牆、側牆、地板、吸頂燈、半拉的窗簾），燈色依樓層主色，夜晚有約 22% 的房間不開燈。營業中的店面一律開燈。

## 5. 燈光

### 5.1 分層

1. **環境（PMREM）**：`SceneProbe` 依時段重建的環境貼圖：天空、地平線、俱樂部側騎樓暖光帶、對面店家暖光、霓虹紅/紫/青色塊。只在霓虹亮度變化一階（1/20）時重建。
2. **主方向光（太陽／月光）**：唯一投影的光源。陰影相機半寬 15m、跟著角色、以 texel 對齊防閃爍；高畫質 2048、中畫質 1024、低畫質關閉。
3. **半球光**：補天光與地面反彈。
4. **局部光（不投影）**：騎樓暖光 3 盞、路燈聚光 4 盞（只在霓虹亮度 > 0.05 時開）。
5. **自發光**：招牌、燈泡、燈籠、販賣機、室內映射窗。

### 5.1.1 室內（1F 麻將館）

- 環境貼圖改用暖色 `HallProbe`（木色地面、天花、吊燈、窗帶）；太陽與天光依 `transition.inside` 壓低。
- 桌燈琥珀色 `#ffc878`（常駐，從街上透過櫥窗看得到）；後牆窗光夜晚冷藍 `#9cc4ff`、白天暖白，形成室內暖 × 窗邊冷。
- 光源數量固定，進出門只改亮度，不能用條件掛載增減光源（會觸發全場 shader 重編、畫面閃一格）。

### 5.2 時段預設

| 時段 | 主光           | 天空 → 地平線 | 霓虹 | 判斷標準                           |
| ---- | -------------- | ------------- | ---- | ---------------------------------- |
| 白天 | 高角度白光     | 晴藍 → 淺藍   | 0    | 招牌字靠底色讀得出來；窗內偏暗     |
| 傍晚 | 低角度橘紅逆光 | 紫 → 橘       | 0.8  | 天空與店面冷暖對比明顯，不是整片橘 |
| 夜晚 | 弱藍月光       | 深藍 → 紫     | 1    | 暗部看得到牆面磁磚；積水映出招牌色 |

## 6. 鏡頭

### 6.1 開場定鏡

- 站在對面人行道（z ≈ 23），低機位（1.6m）微仰，前景馬路、中景俱樂部與左右店面、遠景城市剪影。
- **選單安全區**：桌機選單佔左 1/3，用 view offset 把畫面主體往右推 17%；直向手機選單佔下半部，fov 52、主體往上推 20%。主招牌、直立招牌與入口不得被選單遮住或被畫面邊緣切掉。
- 進入遊戲時 2 秒推鏡，view offset 與 fov 同時內插回跟隨鏡頭，不跳、不黑屏。

### 6.2 跟隨鏡頭

- 室外：距離 7.4m、高 5.2m；室內：距離 6.4m、高 6.6m、轉到斜角看進剖面。直向手機拉遠 1.4 倍。
- 室內時隱藏俱樂部外觀、正面牆切低（剖面娃娃屋）。

## 7. 資產製作流程

1. **規格**：在 [ASSET_MANIFEST.md](ASSET_MANIFEST.md) 登記一列（id、尺寸、三角面預算、貼圖、錨點）。
2. **製作**：Blender 4.x / 5.x。Tripo 等 AI 工具只能當草稿，必須重拓樸、重拆 UV、檢查比例與授權。
3. **匯出**：glTF Binary，1 單位 = 1 公尺、Y 向上、正面朝 +Z；原點依清單（建築：正面牆面中心的地面；道具：底面中心）。套用所有 modifier、刪掉空節點、同材質合併。
4. **命名**：`ARCH_*`（建築）、`PROP_*`（道具）、`CHAR_*`（角色）；材質 `M_<類型>_<名稱>`，會隨日夜發光的材質用 `M_emissive_<名稱>`（程式會依霓虹亮度調整）。
5. **放進專案**：`apps/web/public/club/assets/models/<architecture|props|characters>/<id>.glb`，把 `apps/web/src/components/club/assets.tsx` 的 `ASSET_SLOTS` 該列改成 `ready`。
6. **驗收**：網址加 `?assets=debug` 檢查哪些插槽還是暫代模型（洋紅色標記）；對照本文件 §1.1 與固定鏡頭截圖。

碰撞、互動錨點與尋路只認 `layout.ts` 的座標，所以換模型不會影響玩法；模型要讓出 layout.ts 規定的通行淨空（門 2m 寬、騎樓 3m 深）。
