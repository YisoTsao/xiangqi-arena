## Phase 3 — 暗棋規則引擎 ✅

**依賴**：Phase 1

**任務**：洗牌發牌、翻棋定色、階級吃子、炮跳吃、勝負和棋、可配置 RuleSet。

**驗收**：

- [x] 洗牌後每方 16 子且組成正確（帥1 仕2 相2 俥2 傌2 炮2 兵5）
- [x] 同種子可重現、不同種子不同
- [x] 翻棋定色（含第二位先翻的情況）

- [x] 無子可動判負、無進展和棋、重複局面和棋
- [x] 20 項測試通過

## 技術債與後續改善

| 項目                               | 影響                     | 建議時機                         |
| ---------------------------------- | ------------------------ | -------------------------------- |
| 長捉判定為簡化版（GAME_RULES R-1） | 複雜兌子循環可能判錯     | 有棋友回報爭議時                 |
| 房間只存在單一行程記憶體           | 伺服器重啟 = 房間消失    | 同時在線 > 100 人時導入 Redis    |
| 每次操作送完整快照                 | 流量略高（約 1～3KB/步） | 若加入觀戰或即時模式再改增量同步 |
| 棋子貼圖即時產生                   | 首次進房 50～150ms       | 可改為預生成 sprite sheet        |
| 無 CSP / 安全標頭                  | —                        | 正式上線前加上                   |
