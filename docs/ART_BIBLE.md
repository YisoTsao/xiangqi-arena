# 美術規範（Art Bible）

> 版本 0.1 · 最後更新 2026-10-26

## 1. 美術方向

**「深夜書房裡的一副好棋具」**：溫暖的木質棋盤、象牙色棋子、低調的金色點綴，
在近乎全黑的背景上被一盞暖光照亮。精緻但不浮誇 —— 任何動畫都不應該干擾思考。

三個關鍵字：**溫潤**、**厚實**、**安靜**。

## 3. 字體

- **棋子與標題**：思源宋體／Noto Serif TC → Songti TC → PMingLiU → serif。
  宋體的橫細豎粗最接近傳統刻字。
- **介面**：系統 UI 字體（`system-ui` → PingFang TC → 微軟正黑體）。
- **計時器與房間代碼**：等寬字體 + `tabular-nums`，避免數字跳動。

## 4. 棋盤

### 大盤象棋

- 9×10 交點，間距 1 單位；木板 9.9 × 10.9，厚 0.32。
- 外框雙線、內縱線於河界處斷開、九宮斜線、炮位與兵位的「準星」標記。
- 河界文字「楚　河」「漢　界」左右分置，**兩側皆正向**（不旋轉 180°，
  避免 2.5D 俯視時其中一側看起來是顛倒的錯字）。
- 木板下方有深色底座框與承接陰影的桌面。

### 暗棋

- 8×4 方格，間距 1.2；每格中央有淡淡的菱形紋。
- 手機直向時棋盤自動旋轉 90°（棋子文字保持正向），讓 8×4 的長盤佔滿畫面。

### 貼圖

全部用 Canvas 2D **即時程序生成**，不下載任何圖檔：

- 木紋：確定性亂數產生 140 條弧形年輪 + 3 個木節 + 對角光影漸層。
- 解析度依畫質：高 2048px、中 1536px、低 1024px。

## 5. 棋子

| 項目         | 規格                                                              |
| ------------ | ----------------------------------------------------------------- |
| 形狀         | `LatheGeometry` 旋轉面：上下各有倒角（bevel = 高度 × 0.3）        |
| 尺寸         | 象棋 r=0.44、h=0.24；暗棋 r=0.47、h=0.24                          |
| 側面         | `MeshPhysicalMaterial`，clearcoat 0.6（低畫質關閉）               |
| 正面         | 象牙色徑向漸層 + 細木紋 + 凹刻外環 + 雕刻文字                     |
| 文字立體感   | 另產生灰階 bump map（文字與外環為暗、邊緣漸暗），`bumpScale: 2.2` |
| 背面（暗棋） | 玉石綠徑向漸層 + 金色雙環 + 八角回紋 + 中心金點                   |
| 貼圖尺寸     | 高畫質 512px、其他 256px，依 `side:kind` 快取                     |

## 6. 燈光與相機

- **半球光** 0.55（暖上冷下）提供基礎亮度。
- **主光**：左上方向光 2.1，暖色 `#ffe2b0`，高畫質時投射 2048² 陰影。
- **補光**：右後方向光 0.45，冷色 `#9fb7ff`，勾出棋子輪廓。
- **環境光**：drei `Environment` + 3 個 `Lightformer` 模擬柔光板（低畫質關閉）。
- **接觸陰影**：`ContactShadows`，讓棋子「坐」在棋盤上而不是浮著。
- **相機**：固定 60° 俯角、FOV 34°，**不提供自由旋轉**。
  距離依畫面長寬比自動計算，確保整個棋盤完整入鏡且邊緣留白一致。

## 7. 動畫

| 動畫       | 時長（標準）       | 說明                                     |
| ---------- | ------------------ | ---------------------------------------- |
| Hover 浮起 | 阻尼 14            | 抬升 0.08；選取時 0.2                    |
| 選取光圈   | 循環               | 金色圓環脈動 + 點光源                    |
| 合法落點   | 靜態 / 脈動        | 空點為金色小圓點；可吃子為紅色脈動環     |
| 棋子移動   | 340ms              | ease-in-out + 拋物線弧度（最高 0.45）    |
| 翻棋       | 500ms              | 繞 X 軸旋轉 180° + 同步抬起（正弦曲線）  |
| 吃子       | 220ms 延遲 + 400ms | 被吃棋子上升、旋轉、縮小消失             |
| 最後一步   | 靜態               | 起點細環、終點金色光暈                   |
| 將軍       | 循環               | 紅色脈動環 + 紅色點光源                  |
| 勝利       | 進場               | 金色放射光芒旋轉（12s/圈）+ 卡片升起     |
| 落敗／和棋 | 進場               | 同樣的卡片升起，但無光芒，色調轉灰／玉綠 |

**規則**：

1. 所有動畫**不影響棋局邏輯**。狀態一到就立即可以操作，動畫只是視覺補間。
2. 設定可選「標準 / 快速（×0.5）/ 關閉（×0）」。
3. 尊重系統 `prefers-reduced-motion`：CSS 動畫自動縮為 1ms。

## 8. 效能分級

| 畫質 | DPR 上限 | 陰影     | 環境光 | 接觸陰影 | 貼圖       | 抗鋸齒 |
| ---- | -------- | -------- | ------ | -------- | ---------- | ------ |
| 高   | 2.0      | ✅ 2048² | ✅     | 1024     | 2048 / 512 | ✅     |
| 中   | 1.5      | ❌       | ✅     | 512      | 1536 / 256 | ✅     |
| 低   | 1.0      | ❌       | ❌     | ❌       | 1024 / 256 | ❌     |
| 2D   | —        | SVG 備援 |        |          |            |        |

自動判斷：`deviceMemory ≤ 2` → 低；觸控裝置或寬度 < 768 → 中；其他 → 高。

## 9. 2D 備援

SVG 繪製的平面棋盤，刻意**不模仿** 3D 外觀，而是走乾淨的平面風格：
同一組色票、同樣的棋子文字、同樣的提示標記與 `BoardModel` 介面，
只是沒有透視與光照。棋子移動用 CSS `transform` 過渡，翻棋用 `scaleX` 動畫。

## 10. 介面排版

**桌面（≥ 1024px）**：棋盤主區 + 右側 340px 固定欄（狀態、棋譜、求和／認輸）。

**手機**：棋盤佔據主要視覺空間，上下各一條玩家資訊列，底部三顆按鈕
（求和、認輸、棋譜）。棋譜以底部抽屜（最高 60dvh）呈現。

**觸控**：按鈕最小 40px；棋盤點擊判定以交點為圓心、半徑為格距 0.62 倍，
比棋子本身大，手指不準也點得到。
